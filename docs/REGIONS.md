# Extensions de Rosée et Brume

Huit cartes reliées par des passages aller-retour aux villages existants. Les villages restent des lieux de repos sans mobs. Les niveaux sont configurés dans les spawners, sans plafond ajouté au moteur : ils restent modifiables dans le builder.

| Région | Carte | Niveaux des rencontres |
| --- | --- | --- |
| Rosée | Prairies des Lucioles | 1–2 |
| Rosée | Verger des Ronces | 1–4 |
| Rosée | Bois des Murmures | 3–5 |
| Rosée | Carrière des Échos | 4–5 |
| Brume | Marais des Feux Follets | 1–6 |
| Brume | Ruines de la Veille | 3–8 |
| Brume | Ravin des Cendres | 7–10 |
| Brume | Sanctuaire des Racines | 7–10 |

Rosée → Prairies → Verger → Bois → Carrière.

Brume → Marais → Ruines → Ravin → Sanctuaire.

Les rivières et le ravin se traversent par un pont central. Les chemins gardent les passages accessibles ; les apparitions et patrouilles évitent les obstacles. Les boss occupent les zones les plus avancées, dont la Matriarche araignée à Rosée et le Seigneur gobelin à Brume.
