          Données personnelles et stockage sur l’appareil

          En ligne, le jeu traite notamment le nom de compte, un mot de passe haché, les sessions de connexion, les personnages et leur progression, les relations sociales et les messages de discussion. Les noms et messages peuvent être visibles par les autres joueurs selon les fonctionnalités utilisées. Évitez de publier des informations personnelles dans le chat.

          Ces données servent à gérer les comptes, permettre le jeu multijoueur, sauvegarder la progression et protéger le service. Le navigateur conserve des identifiants de session dans sessionStorage et des préférences dans le stockage local. Le mode solo conserve sa sauvegarde sur l’appareil ; effacer les données du site peut supprimer cette sauvegarde.

          Conservation et suppression

          Les comptes, personnages et sauvegardes de progression sont conservés pour permettre la reprise de l’aventure, jusqu’à une demande de suppression adressée à l’éditeur. Cette règle ne signifie pas que toutes les données techniques sont conservées aussi longtemps. Les sessions de connexion expirent après 30 jours. Le chat global présente au maximum les 50 derniers messages par connexion, en mémoire, et écrit également les messages dans un journal local. Le chat de groupe conserve au maximum 200 messages par groupe et en affiche 50. Ces limites portent sur un nombre de messages, pas sur une durée. Le stockage temps réel n’inclut pas la table de chat dans ses checkpoints Turso ; il ne garantit donc pas la conservation des messages de groupe après reprise du moteur. Aucune purge chronologique automatique des journaux locaux n’est définie dans le code.

          Pour demander la suppression de votre compte et de sa progression, contactez l’éditeur à l’adresse indiquée ci-dessous en précisant votre nom de compte, sans envoyer votre mot de passe. Une vérification de la titularité du compte peut être nécessaire. Le traitement est manuel ; cette page n’ajoute pas de bouton ni de suppression automatique. Les éventuelles copies de sauvegarde des prestataires et leurs délais de purge restent à vérifier.
